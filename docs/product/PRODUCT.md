# Product

## Product in one sentence

「ときまる」（暫定名称）は、幹事がカレンダーから候補日時を選び、参加者が迷わず回答できる私的利用向けの日程調整サービス。キャッチコピーは「みんなの日程、すぐきまる。」。

## Target user and triggering situation

友人、サークル、少人数グループの日程をまとめる幹事と、共有URLから回答する参加者。

## Problem and current workaround

既存の日程調整サービスでは候補日時の手入力や初見で分かりにくい画面が負担になり、参加者の回答操作も煩雑に感じられる。

## Core value loop

幹事が候補日・対象時間帯・所要時間を選ぶと共有URLが生成され、参加者が参加可能な時間帯を回答し、サービスが全員の入る候補を15分刻みで計算する。

## Current phase and evidence

MVP実装中。時間帯と所要時間による候補作成、永続保存、共有URL、複数の参加可能時間帯、候補順位、同一端末での回答修正のローカル動作と本番ビルドを確認済み。需要と初見操作性は未検証。

## MVP scope

- 月間カレンダーで複数日を選択
- 全日共通または日別の対象時間帯
- 所要時間と15分刻みの候補計算
- 日ごとの「全時間参加可能／時間を指定／参加不可」
- 時間指定時の複数参加可能区間
- 共有URL、匿名回答、参加可能人数順の集計
- 予定内での回答者名の重複防止
- 候補日時ごとの参加可能者一覧
- 同じ端末での回答内容の復元と修正
- Googleカレンダー回答案（認証設定後に実装）
- カレンダー未連携時の手動回答

## Later scope

- iPhoneアプリとEventKit
- iCloud、Outlook連携
- 別端末からの回答編集、通知、予定確定後のカレンダー登録

## Explicit exclusions

- 初期版でのAI機能
- 全参加者へのアプリインストール要求

## Success and failure criteria

- 初見の幹事が2分以内に共有URLを作成
- 初見の参加者が手動で1分以内に回答
- 5人中4人以上が説明なしで完了
- Google連携時に予定名や場所を保存しない

## Key assumptions and risks

- Google連携への同意率と利便性は未検証
- iCloudを主に使う参加者への自動回答は初期版では提供できない
- 匿名URLの推測耐性、編集権限、保存期間は公開前に強化が必要
- Google予定で空き区間が複数ある場合の自動回答仕様は技術スパイクで確認する

## Open questions

- データ保存期間
- 回答編集の本人確認方法
- Google OAuthの審査と同意画面

## Next action

ローカルMVPを利用者シナリオで操作確認し、Google OAuth連携の技術スパイクへ進む。
